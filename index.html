基于帆软报表 + MES + SpringBoot 的 Q-Time 自动化报表实战

发表于 2026-04-15 分类于 02-项目 ， 06-FR 本文字数： 2.1k 阅读时长 ≈ 8 分钟

记录制造业 Q-Time 报表自动化落地实践。项目基于帆软报表、MES系统与企业内部SprinBoot平台，实现了 Q-Time 比率统计报表与 Q-Time 明细报表的自动化建设。

项目初期，统计报表与明细报表耦合在同一个模板中，由于比率统计依赖大量动态 SQL 单元格计算，导致每次打开明细报表也会触发复杂聚合查询，整体性能极差。后续通过拆分报表、建立部门—站点—工序关系模型、引入内部系统平台动态维护周期目标与责任归属，实现了报表性能优化与业务解耦。

项目难点主要包括：

  • MES Oracle 与内部系统 MySQL 双数据库联合查询
  • 工序与部门关系不在 MES 中维护
  • Q-Time 责任归属动态计算
  • 周/月/年/日多周期统计
  • 动态折线图与交叉表生成
  • 帆软动态 SQL 性能优化

最终实现：

  • Q-Time 比率统计报表
  • Q-Time 明细追踪报表
  • 内部系统 后台目标配置系统
  • 工站与部门动态维护平台
  • 多周期自动化趋势分析

有效减少了质量部门人工统计时间，提高了报表查询效率与数据准确性。
