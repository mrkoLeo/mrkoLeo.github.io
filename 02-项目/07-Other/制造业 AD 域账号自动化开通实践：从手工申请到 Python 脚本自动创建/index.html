什么是 AD（Active Directory）

Microsoft Active Directory 是微软提供的企业级目录服务。

它本质上是：

企业内部的“统一身份认证中心”。

所有账号、权限、计算机、组，都统一存储在 AD 中。

什么是域控（Domain Controller）

域控服务器（DC）负责：

  • 用户认证
  • 密码校验
  • 权限控制
  • 组策略
  • 统一登录
