MES系统运维自动化实践：管理员账号创建与角色权限自动开通

发表于 2025-11-14 分类于 02-项目 ， 02-MES 阅读次数： 本文字数： 1.7k 阅读时长 ≈ 6 分钟

在制造业 MES 系统日常运维中，管理员账号开通与角色权限分配是一项高频但重复性的工作。传统人工处理方式不仅耗时，还容易因权限组遗漏、角色配置错误而导致系统使用异常。

本文基于 Python + MES OpenAPI，实现了一套自动化用户开通脚本，支持：

  • 自动登录 MES 系统
  • 自动检测用户是否存在
  • 自动创建管理员账号
  • 自动绑定 MES 角色权限
  • 自动生成日志记录

通过脚本化方式，大幅降低了重复操作成本，提升了账号开通效率与权限配置准确率，为 MES 运维自动化提供了一套可复用方案。

背景

在日常制造业信息化运维过程中，品微 MES 系统经常需要为以下人员开通管理员权限：

  • MES 管理员
  • 生产主管
  • 工艺工程师
  • 品质人员
  • IT 运维人员

由于 MES 系统权限控制较细，不同岗位对应不同角色组，因此每次开通账号时，都需要：

  1. 创建 MES 用户
  2. 核实用户基础信息
  3. 检查权限角色
  4. 手动勾选权限组
  5. 验证角色是否正确

随着系统规模扩大，这类操作频率越来越高。

遇到问题

人工开通流程繁琐

传统方式需要管理员登录后台后：

  • 搜索用户
  • 手动新增
  • 配置邮箱
  • 分配角色
  • 保存权限

整个流程步骤较多。

权限组容易遗漏

MES 系统角色较多：

  • 系统管理员
  • 工艺管理员
  • 生产管理
  • 设备管理
  • 报工管理
  • 数据查询
  • 看板权限

人工选择时容易：

  • 少选权限
  • 选错权限
  • 权限继承异常

导致后续用户无法正常使用系统。

重复性工作严重

由于账号开通属于高频操作：

  • 新员工入职
  • 岗位调整
  • 临时权限申请
  • 项目上线

都会重复执行同样流程。

运维人员大量时间消耗在重复点击上。

痛点是什么

整个流程的核心痛点主要有以下几点：

痛点 描述
重复劳动 相同操作每天重复执行
容易出错 权限组配置依赖人工
缺乏标准化 不同管理员配置方式不同
无日志追踪 后续难以审计
开通效率低 一个账号需要多次确认

尤其是在生产环境中，一旦权限漏配，会直接影响：

  • 生产报工
  • 工单流转
  • 数据录入
  • MES 操作权限

严重时甚至会影响生产。

功能 API
登录 /api/base/user/login
查询用户 /api/base/user/getUsers
创建用户 /api/base/user/addUser
查询角色 /api/base/role/getRoles
查询角色用户 /api/base/role/getRoleUsers
更新角色成员 /api/base/role/updateRoleUser

因此完全可以通过 Python 调用 API 实现自动化。
