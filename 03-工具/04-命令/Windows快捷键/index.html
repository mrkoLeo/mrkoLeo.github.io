Windows 常用快捷键

发表于 2025-09-02 分类于 03-工具 ， 04-命令 阅读次数： 本文字数： 667 阅读时长 ≈ 2 分钟

本文整理了 Windows 系统中常用且高频的快捷键与运行命令，包括文件管理、窗口切换、分屏操作、截图、浏览器、CMD / PowerShell 等常见场景。

内容按功能分类，涵盖日常办公、开发运维、多任务处理等实际使用需求，并补充了一些隐藏但非常实用的系统快捷操作，适合作为 Windows 效率工具速查手册长期收藏。

Windows 常用快捷键

按使用场景整理，很多都是日常高频。

一、最常用

快捷键 功能
Ctrl + C 复制
Ctrl + V 粘贴
Ctrl + X 剪切
Ctrl + Z 撤销
Ctrl + Y 重做
Ctrl + A 全选
Ctrl + S 保存
Ctrl + F 查找
Alt + Tab 切换窗口
Win + D 显示桌面
Win + E 打开资源管理器
Win + L 锁屏
Win + R 打开运行
Win + I 设置
Win + Tab 任务视图
Ctrl + Shift + Esc 任务管理器
Alt + F4 关闭窗口

二、文件管理快捷键

快捷键 功能
F2 重命名
Delete 删除
Shift + Delete 永久删除
Ctrl + N 新建窗口
Ctrl + Shift + N 新建文件夹
Alt + Enter 属性
Backspace 返回上一级
Alt + ↑ 上一级目录
Ctrl + 鼠标滚轮 调整图标大小

三、窗口管理

分屏

快捷键 功能
Win + ← 窗口靠左
Win + → 窗口靠右
Win + ↑ 最大化
Win + ↓ 最小化
Win + Shift + ←/→ 窗口移到另一显示器

虚拟桌面

快捷键 功能
Win + Ctrl + D 新建桌面
Win + Ctrl + ←/→ 切换桌面
Win + Ctrl + F4 关闭桌面

Win + Shift + S 截图工具
