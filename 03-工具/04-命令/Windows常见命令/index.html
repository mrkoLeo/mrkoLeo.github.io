Windows常用命令

发表于 2025-09-02 分类于 03-工具 ， 04-命令 阅读次数： 本文字数： 1.9k 阅读时长 ≈ 7 分钟

本文整理了 Windows CMD 与 PowerShell 中常用且高频的命令，包括文件管理、进程控制、网络诊断、系统运维、磁盘管理、权限控制以及开发调试等场景。

同时对 PowerShell 常见 Alias（命令别名）进行了归纳，并补充了端口占用查询、杀进程、WiFi 密码查看、批量执行命令等实用组合示例，适合作为 Windows 开发、运维与日常使用过程中的命令速查手册。
